# CaMa-Flood v5 Tutorials

These tutorials introduce reproducible CaMa-Flood workflows through written specifications, executable examples, and learner-facing manuals. Tutorial workflows and outputs are for learning and operational checks; they are not automatically scientific validation.

| Tutorial | Learning objective | Manual |
| --- | --- | --- |
| [Tutorial01 — Get Started](tutorial01-get_started/tutorial_design.md) | Prepare the v5 environment, build the model, understand map/runoff inputs and GOSH settings, and run a short Mekong sample. | [Beginner manual](tutorial01-get_started/manual_tutorial01-get_started.md) |
| [Tutorial02 — Mekong NetCDF four-experiment comparison](tutorial02-mekong_netcdf_4exp/tutorial_design.md) | Run annual NetCDF experiments and compare routing, bifurcation, and floodplain configurations. | Manual not yet prepared. |

## How the tutorial framework works

Each tutorial has a `tutorial_design.md` defining the experiment and expected results. When designed, `design/manual_design.md` specifies the learner and teaching goals. Shared agent instructions describe implementation and manual authoring. These documents are refined from source inspection and execution evidence; human experts retain scientific and educational review.

**Contributors:** see [How to develop tutorials](how_to_develop_tutorials.md) for the full process and Tutorial01 as a worked example.
