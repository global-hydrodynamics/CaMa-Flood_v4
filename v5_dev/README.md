# Archived CaMa-Flood v5 Development Files

This directory preserves the v5 development tree that was maintained inside the CaMa-Flood v4 repository before v5 development moved to its own repository. It is retained as historical and development reference material; it is not the current v5 source of truth.

## Current v5 development

Continue CaMa-Flood v5 development in the independent [global-hydrodynamics/cmf_v5_beta repository](https://github.com/global-hydrodynamics/cmf_v5_beta). Use that repository's current `AGENTS.md`, documentation, and project status for development instructions and supported workflows.

## Archive limitations

The files here preserve their pre-migration contents and may refer to the former repository layout, branches, paths, or build configuration. Scripts and workflows have not been adapted or verified for execution from `v5_dev/` in the current v4 checkout. In particular, do not assume that relative paths, repository-root discovery, build settings, data locations, or generated-output locations still work.

Do not continue new v5 feature development in this archive. The v4 repository is maintained for v4 use, bug fixes, manuals, and historical reference; this archive should only be consulted when historical context is needed.
