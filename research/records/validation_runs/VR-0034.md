- Validation ID: `VR-0034`

- Environment: macOS arm64, Python 3.13.3, GNU Fortran 14.2.0.
- Dataset: Git-tracked Mekong map sample; read-only runoff climatology from the separately distributed local package copied into the temporary test tree.

## Checks and results

Command: `CMF_RUNOFF_CLIMATOLOGY=<package runoff file> python3 -B -m unittest map.tools.tests.test_bifurcation_migration -v`.

All three tests passed:

- Missing `rivhgt.bin` is rejected before invoking fake executables or creating outputs, with a message directing the user to run s01.
- The shared v5 s02 and legacy v4 tools produced byte-identical `bifprm.txt`, `bifbsn.bin`, `bpoint.bin`, `bifmod.bin`, and `bifcol.bin` on separate temporary Mekong copies. The optional `check_bif_dphwth.bin` matched the legacy two-record `bifdph.bin` byte-for-byte; default s02 did not emit either diagnostic file.
- The full integration ran actual s01 in a temporary map workspace, confirmed its `rivhgt.bin`, then ran s02 and verified its five standard outputs.

During test authoring, an initial assertion incorrectly treated textual `bifprm.txt` as a one-record binary raster and failed its size check (63,164 bytes observed versus 38,400 expected). The assertion was corrected to check binary map products only; the final run above passed.

## Interpretation and limits

This is migration-regression and workflow-integration evidence for the tested compiler and Mekong sample. It is not an independent scientific validation, full CaMa-Flood simulation, cross-compiler comparison, or validation on other maps.
