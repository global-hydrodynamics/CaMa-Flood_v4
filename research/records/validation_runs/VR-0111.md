## Observed result

Both model builds succeeded. All five focused tests passed. An existing-style Namelist without `CMF_BASE` or `COUTVAR_TABLE` still produced its ordinary `outflw` Binary output. The maintained sample writes its resolved repository root in `&NOUTPUT`; a blank table setting selected the default registry, while the explicit temporary path selected the reordered registry. A nonexistent configured table stopped initialization with `Cannot open output registry: <attempted path>` and left no runoff output. Python syntax, Shell syntax, and whitespace checks passed. The active implementation and sample scripts contain no environment lookup for `CMF_BASE` or `CMF_OUTPUT_VARIABLES`.
