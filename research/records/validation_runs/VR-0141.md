## Implementation

All panels use 102–109°E, 10–17°N. f02a strengthens local shafts from 0.007
to 0.010 inches and changes blue to black; orange curved Flexible Downstream
links remain distinguishable. f02b uses all-black arrows and six full-map
log-area thickness classes (0.008–0.032 inches), with representative area
legend strokes. f02c retains the upstream-area concept using the package's
`shade_rainbow` palette and logarithmic color normalization, moderate widths
(0.008–0.022 inches), and categorical dark-gray `bsncol` background.

The wrapper has three explicit panel calls followed by one unchanged combine
step. All share the existing reserved colorbar geometry: a/b hide that slot,
c uses it. Renamed b's option to `upstream_area_thickness`; moved the colored
`upstream_area` representation to c, including filenames and discovery text.
README embeds the composite only; all four project PNGs are tracked. The
shared figure-making rules and Gallery are unchanged.
