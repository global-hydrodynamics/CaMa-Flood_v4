## Implementation and scientific interpretation

f01a retains upstream area in km², full-valid-map LogNorm, YlGnBu, missing-value
mask and the original 90–110°E, 5–35°N extent. f01b reads `basin` directly:
414 original positive integer IDs are retained in the image array. Its discrete
tab20 palette repeats across IDs; repeated colors do not mean equal IDs and
numeric differences are not continuous physical differences. f01c reads the
five used `bsncol` indices unchanged; its tab10 RGB colors are mixed with 60%
opaque white. Color assignments and geographic boundaries are not recomputed.

Inspected `map/tools/code/region_set_map.F90` and its wrapper/README under
`map/tools/script_region/`. The preparation code labels network paths, reorders
IDs by upstream-grid count, then assigns display colors using neighboring-color
checks, with special handling for single-cell basins. Each of the 414 IDs in
the sample maps to one of the five stored display indices, with equal masks.
`bsncol` is not invertible to basin identity. The README links that code and the
existing `map/tools/script_bin2nc/s02-convert_netcdf.sh` preparation template;
plotting does not rerun map preparation or alter these inputs.

The former f01b Basin Color Python/PNG pair was moved to f01c with `git mv`.
The elevation/width script and PNG pairs were removed; f01b Basin is new.
The catalog has exactly three f01 entries and preserves both f02 rows unchanged.
The development guide's discovery example now uses available area/basin methods
instead of pointing to the retired width option. Historical records are intact.
