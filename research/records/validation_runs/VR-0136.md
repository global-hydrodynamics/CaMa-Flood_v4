## Checks and results

`python visualization/river_map/script/test_river_network_layout.py` runs the real
independent panel entry points at 100 DPI with automatic sizing, height-only
4/6/8-inch sizing, and 6-inch height plus a 4-inch width limit. All five cases
pass: identical PNG sizes, map bounds and data-to-display transforms, aligned
colorbar top/bottom, complete label bounding boxes, separated major tick labels,
and an exactly white f02a reserved region. Tests deliberately set
`savefig.bbox='tight'`; export preserves the full canvas regardless. Height-only
exports are 400/600/800 pixels tall; the width-limited export is 400x341 pixels.

`bash visualization/river_map/f02-line_river_map.sh` (with `.venv/bin` on PATH,
Agg backend and a writable Matplotlib cache) regenerates all three tracked f02
PNGs. At 200 DPI both panels are **1393x1188 pixels**. Renderer-derived rectangles
in exported pixels, measured from the lower-left canvas corner:

| Rectangle | x | y | width | height |
| --- | ---: | ---: | ---: | ---: |
| Map, both panels | 144 | 124 | 968 | 968 |
| Colorbar, both panels | 1148 | 124 | 36 | 968 |

The unchanged combiner produces **2400x1037 pixels** using the existing 12x8-inch
maximum settings. A scan of dark horizontal frame pixels finds both map top
edges at row 100 and bottom edges at rows 912–913 (antialiasing included);
renderer equality and common composite scaling preserve geographic pixel
scale as well. Visual review confirms
readable labels and no clipping or overlap in the default composite.

Scientific drawing code is unchanged: each panel has 3,150 nextxy links (3,022
local, 128 curved Flexible Downstream), 1,374 direct segments intersecting the
view, no stations, unchanged raster/masks/colors and drainage-area scaling.
The previous `imshow` set equal-degree aspect after the geographic helper;
this effective aspect is explicitly preserved rather than silently changed.
An in-memory baseline comparison executed both original panel scripts from
the starting commit and the edited scripts with intercepted save functions.
Exact equality passed for quiver positions/vectors/values/styles, background
data and masks, normalization, colors, flexible-arrow endpoints/curvature,
line widths, geographic limits, and the effective axes aspect.
No model simulation or scientific validation is claimed.

`git diff --check` and `python research/validate_records.py` pass. Gallery files,
the top-level Gallery listing, the combiner, and the shared figure guideline
are unchanged. The brief knowledge-gap review found no material new scientific
or architectural questions. This remains an experimental f02 layout.
