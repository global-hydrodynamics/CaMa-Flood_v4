# VR-0146: p01-f03b extended outlet vector map

Task DT-0100; instruction EV-0466, implementation EV-0467, validation EV-0468.
Baseline commit `50325ce1b80480c60d933f7542e003aaee65e7e2`; branch
`manual-automation`. Changes remain uncommitted as instructed.

The panel follows Tutorial02 Figure 1c. It draws every valid `nextxy` main
link between stored unit-catchment outlets. `bifprm.nc` indices resolve both
endpoints through `outlon`/`outlat`; positive first-layer width identifies
channel bifurcations, and the remaining valid paths are overland bifurcations.
Four main-channel classes use full-map source-area quartiles; the independent
channel-bifurcation colors use quartiles of first-layer path width. High-resolution
`catmxy` records map 1-minute pixel centers to coarse cells; guide origins are
the average assigned-pixel coordinates for cells with no incoming valid
regional main link.

Real-data rendering reports 3150 main links (430 intersecting the view), 77
channel bifurcations (18 visible), 305 overland bifurcations (113 visible), and
4426 headwater guides (182 visible). Of the headwater candidates, 220 touch
the outer map edge and may be regional truncations. No invalid map endpoints,
widths, outlet coordinates, or centroid guides were excluded; 743868 high-res
pixels carry unassigned/sentinel catmxy values and are omitted. Main, bifurcation,
and guide endpoints are checked against the stored indices/coordinates.

The wrapper generated f03a, f03b and the combined 3375 × 1600 px Figure at
200 dpi. A separate width-fixed f03b render measured 1200 × 1124 px. Rendering
f03a with its original 8-inch height and default extent produced pixels exactly
identical to the prior tracked panel. The combined PNGs were visually reviewed.
Shell syntax, Python compilation, README path checks, catalog registration and
`git diff --check` pass. The shell explicitly selects Matplotlib's Agg backend
for saved-image generation; an initial macOS interactive-backend attempt aborted.

These checks validate visualization data handling and rendering only. They do
not validate model science. Outlet-to-outlet lines are straight geometric links,
and regional no-incoming-link candidates are not necessarily physical
headwaters. No model run or Gallery publication occurred. Knowledge-gap review
found no additional material scientific or architectural question.
