# VR-0115: Model-side bifurcation input and Restart integration

- **Validation ID:** VR-0115
- **Event ID:** EV-0365
- **Task ID:** DT-0070
- **Source commit:** `f7e23330` (implementation and validation source)
- **Environment:** macOS workstation; GNU Fortran/OpenMP; NetCDF-Fortran 4.6.2; NetCDF-C 4.9.3; `ncdump` and `ncgen`
- **Dataset:** Mekong 15-minute map, 80 × 120; 382 pathways and 5 layers; daily one-degree runoff sample for Jan 2000. The user-generated `bifprm.csv` and `bifprm.nc` were inspected and used read-only, not staged.

## Commands and observations

Both standard and NetCDF-enabled model builds were made from isolated copies in `/tmp`, avoiding repository build artifacts. Temporary Mekong run scripts used one-day periods and `/tmp` run directories. The standard model read CSV and legacy TXT; the NetCDF-enabled model read `bifprm.nc`, wrote `o_pthflw2000.nc`, and created a NetCDF Restart. All three reported 382 paths and 5 layers and completed successfully.

The CSV and TXT one-day outputs matched exactly for the tested gridded variables and Binary pthflw payload. `ncdump` confirmed the pthflw file contains pth_id, endpoint indices, source/outlet coordinates, length, elevation, depth, width, and ascending basin IDs. CSV IDs, indices, basin IDs, lengths, elevations, depths, and widths matched the NetCDF output; end coordinates differed only by float32 representation (maximum 5e-5 degrees longitude and 4.96e-6 degrees latitude). With a 12-hour output interval, the Binary and NetCDF pthflw Float32 payloads matched exactly for both time records after high-precision NetCDF inspection. The five gridded output variables also matched bitwise across two records, including identical missing-cell masks.

A matching Normal NetCDF Restart continuation succeeded. A Storage-only NetCDF Restart retained path IDs/endpoints and omitted `pthflw_pre` as intended. Copies with modified `pth_id` and modified `ix` failed with a row-specific path identity diagnostic. Removing all path identity variables produced the expected compatibility warning and continued; retaining only a partial identity set was rejected. The source Restart and generated map files were not modified.

## Result and limits

The tested model I/O contracts and restart validation pass for this Mekong configuration. This is not an independent validation of bifurcation hydraulics or a long-term scientific comparison. Optional MPI and optional-scheme combinations were not separately rerun. The legacy `bifori.txt` coordinate header/reader discrepancy remains unchanged. Binary Restart does not carry path identity metadata and therefore requires the same configured path ordering.
