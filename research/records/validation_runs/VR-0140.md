# VR-0140: Display-only pseudo-log categorical basin legend

- Task: DT-0095 follow-up; instruction EV-0448, implementation EV-0449,
  validation EV-0450; approved branch `manual-automation`.
- Starting commit: `551e474ea3674eeebf5162d63d2c2f4edd177cde`.
- Maintainer request: expand categorical basin IDs 1–20 in the legend and
  compress higher IDs without applying scientific log normalization or changing
  map colors. Existing completion instructions authorize commit and push.

## Approach

After inspecting the existing `BoundaryNorm` map and uniform colorbar, chose a
custom legend mesh in the existing reserved axis. Each ID through 20 occupies
one display slot. Each later interval ending at 30, 40, 50, 70, 100, 150, 200,
300 and the maximum ID also occupies one slot, compressing its individual
swatches. Every swatch uses the map's unchanged raw-ID palette and BoundaryNorm.
Only legend coordinates are piecewise transformed; both axes remain linear,
with no logarithm or LogNorm for basin IDs. Tick font size adapts to panel height.
README, script comments, and the catalog method description explain these
display semantics. Basin IDs remain categorical and repeating colors are not
unique identifiers.
