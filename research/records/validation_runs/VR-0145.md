# VR-0145: p01-f03a outlet-based vector river map

Task DT-0099; instruction EV-0463, implementation EV-0464, validation EV-0465.
Baseline commit `eb6610c0b1a51f1dc37c70010dfed7093be8a552`; branch
`manual-automation`.

The new panel reads the Git-tracked Mekong `uparea.nc`, `nextxy_noedge.nc`,
`lonlat.nc`, and `params.txt`. Positive one-based `nextxy` destinations were
resolved to valid river cells and connected using the corresponding stored
`outlon`/`outlat` coordinates. All 3150 valid links were rendered. Source-cell
areas (m² converted to km² for display) were classified into four quartiles
computed over full-map valid links; cutoffs were 734.50, 1707.89, and
7277.43 km². No invalid destinations or outlet endpoints occurred.

The Bash wrapper and Python compile checks passed. The wrapper generated both
project-local PNGs; visual inspection confirmed the intended uncluttered white
background and outlet-based connections. At 200 dpi the 8-inch-height export is
1699 × 1600 pixels, and a width-fixed 6-inch/automatic-height panel is
1200 × 1129 pixels. The Figure-level image is byte-identical to the panel.
Catalog registration and `git diff --check` pass.

This validates the visualization's data handling and rendering, not the model's
scientific behavior. Straight segments show endpoint relationships rather than
traced channel centerlines. Knowledge-gap review found no material new
scientific or architectural questions.
