# Detailed validation records

The analysis-oriented index is `research/validation_runs.csv`. Create a `VR-####.md` detail record from [`research/templates/validation_run.md`](../../templates/validation_run.md) only when the command, comparisons, or interpretation need more space. Record source revision, worktree state, exact environment and dataset identifiers, expected/observed values, and limits. Keep logs with secrets or restricted data outside the repository.
