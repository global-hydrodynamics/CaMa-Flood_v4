- Observed: FLOW documents and assigns `catmxy=-9999` for sea and `catmxy=-999` for pixels without an assigned unit catchment. Raw `catmzz` and `catmz100` arrays initialize to -99 for sea and -9 for unassigned catchments. FLOW `merge_hires` sets profile values to -9 wherever `catmxy <= -900`, collapsing both cases. The v5 `region_combine_hires` copies available profile values unchanged and uses -9 as its fill when an input layer is unavailable. In the Mekong sample, all 690,773 `catmxy=-9999` cells and all 53,095 `catmxy=-999` cells have `catmzz=-9` and `catmz100=-9`. This resolves the earlier apparent mismatch as distinct layer/stage conventions.
