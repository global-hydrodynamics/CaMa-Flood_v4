## Failure discovered and handling

The first temporary full-workflow attempt passed a long absolute temporary path to the legacy Fortran argument reader. Source inspection confirms runoff and dimension arguments are read through `A128` format descriptors, and the temporary path was truncated, causing a missing-record runtime error. The v5 wrapper now uses short map-root-relative defaults and rejects configured argument strings longer than 128 characters. The regression was rerun with these paths and passed. No Fortran input interpretation or numerical routine was changed.

## Interpretation and limits

Exact output equality supports mechanical compatibility for this Mekong fixture, compiler, and configuration; it does not establish scientific validity, other maps/compiler settings, or the optional NetCDF build path. The full model was not run. The current core reader still reads `rivwth.bin`, so automatic selection of `rivwth_merit.bin` remains separate work. The ELSE_GPCC redistribution terms remain unresolved; no data file was added to GitHub.
