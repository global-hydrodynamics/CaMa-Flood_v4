# VR-0113: NetCDF bifurcation-path output

- **Validation ID:** VR-0113
- **Event ID:** EV-0359
- **Task ID:** DT-0068
- **Source commit:** `85cd95a0264df5a085c6f00c141e9d07d1a22037`
- **Environment:** macOS; GNU Fortran/OpenMP; NetCDF-Fortran 4.6.2; NetCDF-C 4.9.3; Python 3; `ncdump`
- **Dataset:** Mekong 15-minute map, 382 bifurcation paths with five layers, and the one-day runoff sample

## Commands and observations

The Binary model was built cleanly with `make clean && make all` under `src_main/`. The NetCDF model was built with `./gosh_sample/compile_netcdf.sh`. The focused suite ran with:

```sh
python3 -B -m unittest gosh_sample.etc.test.test_output_aliases -v
```

All ten tests passed. The new pthflw test generated Binary and NetCDF output at a six-hour interval, yielding four records. It verified that the NetCDF variable is Float32 with Restart-compatible `NPTHOUT × NPTHLEV × time` Fortran dimensions (`time, NPTHLEV, NPTHOUT` as displayed by `ncdump`), has registry-driven metadata, uses shuffle and deflate level 3, has four strictly increasing time coordinates, and omits `_FillValue` because the registry defines no sentinel. All nonzero NetCDF values read back at Float32 precision matched the four direct-access Binary `.pth` records byte-for-byte. A temporary registry override changed the NetCDF `long_name`, demonstrating that the standard metadata path is used.

## Result and limits

`pthflw` now uses the established `pthflw_pre` Restart dimension convention. It writes the existing output-interval average `D1PTHFLW_oAVG` after conversion to Float32 and calls the same `CMF_MPI_AllReduce_R1PTH` routine used by the Binary path. The Binary path retains its direct-access record size, order, and writer. The Restart module was not modified.

This sample test verifies the output layout and selected data transfer behavior, not independent scientific correctness. MPI execution was not run; only the existing MPI aggregation routine was reused by source inspection. No Restart code or calculation of bifurcation flow was changed.
