# VR-0057: Validate the permanent-water workflow migration

- Validation ID: `VR-0057`
- Event ID: `EV-0173`
- Task ID: `DT-0020`
- Source commit: `de8196968d8597867ebad9566e173aae9b187a66`; pre-existing dirty worktree retained
- Environment: macOS arm64, gfortran and Python 3.13; see [`environment_inventory.md`](../../baseline/environment_inventory.md)
- Dataset: tracked Mekong `params.txt`, base `nextxy.bin`/`ctmare.bin`, and `1min` inputs; all writes were isolated in temporary directories

## Commands and checks

- `make -B -C map/tools/code param`
- `python3 -B -m unittest discover -s map/tools/tests -p 'test_*.py' -v` (full tools suite; includes nine permanent-water tests)
- `python3 -B map/tests/validate_map_variables.py` and `python3 -B research/validate_records.py`
- Compile legacy and migrated programs separately and compare outputs on the Mekong sample.
- Compare legacy and migrated outputs on a 2 x 2 synthetic map with `grdare.bin` omitted.
- Run the Mekong s05 wrapper from a temporary map-shaped directory with symlinked read-only sample inputs.
- `sh -n` on both wrapper copies; inspect their only textual difference (the sample-specific header).
- Validate the registry, research records, relative links, scoped whitespace, and protected-file list.

## Results

The shared `param` target built successfully. The complete `map/tools/tests/` suite had 54 passing tests and one existing runoff-data-dependent skip; all nine permanent-water tests passed. The Mekong comparison produced two 38,400-byte files that were byte-identical: 6,566 valid catchments, identical missing-value masks, zero differing valid cells, and maximum absolute difference 0. The new program reported 86,319 selected pixels, no catchment caps, and use of supplied `grdare` data. The synthetic missing-`grdare` fallback outputs were byte-identical at 16 bytes. The shell wrapper completed successfully in the temporary map-shaped workspace and wrote a 38,400-byte `prmwat.bin` there.

## Interpretation and limits

These results establish buildability, tested input-error handling, and output compatibility for the inspected Mekong reference and one small fallback fixture. They do not scientifically validate the permanent-water classification, the derivation of the 5 m threshold, or the numerical accuracy benefit of the fallback. No large-map run or simulation was performed. The source sample was not changed.
