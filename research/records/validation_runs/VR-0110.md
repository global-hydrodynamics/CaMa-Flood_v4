# VR-0110: Runoff output alias compatibility

- **Validation ID:** VR-0110
- **Event ID:** EV-0350
- **Task ID:** DT-0065
- **Source commit:** `b70089959784575606e3632560c9bf0e07f86d42`
- **Environment:** macOS workstation; GNU Fortran/OpenMP; NetCDF-Fortran 4.6.2; NetCDF-C 4.9.3; Python 3; `ncdump` available
- **Datasets:** tracked Mekong 15-minute sample map; test-generated model outputs and reordered registry files in temporary directories

## Command and expected result

Built the Binary model with `make -C src_main clean all` and the NetCDF-enabled model with `./gosh_sample/compile_netcdf.sh`. Ran:

```sh
python3 -B -m unittest gosh_sample.etc.test.test_output_aliases -v
python3 -m py_compile gosh_sample/etc/test/test_output_aliases.py
sh -n gosh_sample/mek01-default_run.sh \
  gosh_sample/mek02-longterm_netcdf.sh \
  gosh_sample/legacy02-longterm_netcdf.sh
git diff --check
```

The focused integration tests exercise canonical and alias requests for Binary and NetCDF output, check output filenames and NetCDF variable names, compare alias values exactly, reorder the CSV columns, and disable `LROSPLIT` for each subsurface name. Expected alias pairs are `runoff`/`rofsfc` and `runoffsub`/`rofsub`; disabled subsurface output must fail during initialization without leaving output files.

## Observed result

Both model builds succeeded. All three integration tests passed. Binary and NetCDF alias outputs retained the requested names and contained exactly matching numerical arrays for each canonical/alias pair. NetCDF aliases inherited canonical metadata even with reordered CSV columns. `runoffsub` and `rofsub` both failed consistently when `LROSPLIT` was disabled, before any requested or preceding output file was created. Python compilation, Shell syntax checks, and `git diff --check` passed.

## Result and limits

- **Result:** pass
- **Comparison method:** Exact array equality between canonical and alias outputs; exact checks of requested names and inherited metadata; expected initialization failure and absence of output files for disabled `LROSPLIT`.
- **Scientific interpretation:** These checks validate the output-registry and Binary/NetCDF interface behavior for the two requested alias pairs. They do not independently validate runoff science or cover unrelated output variables and every optional scheme.
