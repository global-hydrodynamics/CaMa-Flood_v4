## Interpretation and limits

This is byte-identical program regression for one Mekong sample and one runoff-grid configuration, using the same compiler and flags. It supports preservation of the tested metadata and binary output. It does not validate all grid geometries, absent-`grdare` fallback, multi-area maps, maximum-contributor edges, other compilers, the CaMa-Flood simulation, or scientific correctness. The generator does not read runoff values; the input-grid configuration must match the user's runoff product metadata.
