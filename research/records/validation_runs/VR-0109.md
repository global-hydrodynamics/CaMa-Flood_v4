## Result and limits

- **Result:** pass
- **Comparison method:** The sample runoff converter compares packed Float32 values exactly after NetCDF read-back. The representative map conversion uses its existing source-to-output read-back validation. Runtime checks establish compressed-file reader compatibility for this Mekong configuration, not scientific correctness or all optional combinations.
- **Scientific interpretation:** No scientific algorithm was changed. Existing external compression libraries provide their own lossless codec implementation; these checks validate CaMa-Flood's output settings and data handoff, not zlib/HDF5 internals. ERA5-Land writer runtime behavior was not executed because required Python dependencies are missing. The legacy channel-parameter writer remains NetCDF classic 64-bit-offset because compression is unavailable in that established format. LWEVAP still depends on a third forcing field that the current runoff reader does not populate; behavior was inspected and left unchanged.
