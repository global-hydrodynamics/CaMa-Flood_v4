## Manual semantic-discovery review

| Request | Candidate selected | Scientific reason |
| --- | --- | --- |
| Plot river width on a map. | p01-f01d: raster_river_map-merit_merged_width | Width field and map representation; inspect product suitability. |
| Show channel width as colored grid cells. | p01-f01d: raster_river_map-merit_merged_width | Raster representation of channel width. |
| Create a raster map of MERIT-based river widths. | p01-f01d: raster_river_map-merit_merged_width | Technique and MERIT Hydro-merged product both match. |
| Show downstream connectivity. | p01-f02a: vector_river_network-connectivity_type | Directed nextxy connections distinguish local and flexible links. |
| Draw arrows between river grid cells. | p01-f02a: vector_river_network-connectivity_type | Explicit center-to-center directed links. |
| Visualize the CaMa-Flood river network. | p01-f02a or p01-f02b: vector_river_network | Choose connectivity classes or upstream-area styling according to intent. |

These are manual interpretation checks, not a new search engine. Generic width
requests do not prove that MERIT-merged width is the intended model input.
The README explains that elevation means river-cell channel-top elevation,
basin colors are display indices, and contributing area is not discharge.
No new naming decision requiring scientific judgment remains. The brief
knowledge-gap review found no material new scientific or architectural gap.
