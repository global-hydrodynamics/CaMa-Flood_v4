# DR-0018: Distinguish runoff-grid tags from high-resolution map tags

- Discussion ID: `DR-0018`
- Linked event IDs: `EV-0115`, `EV-0116`, `EV-0117`
- Source type: Codex task instruction
- Source reference: Maintainer-approved task in active conversation, 2026-11-01; no stable archive ID
- Source access: restricted
- Maintainer review: pending

## Maintainer-approved decision

Use `ROFFTAG` to identify a runoff product and its input-mapping configuration. Derive the paired filenames as `inpdim_${ROFFTAG}.txt` and `inpmat_${ROFFTAG}.bin`. Keep `HIRES_TAG` separate for high-resolution map resolution/directory selection (for example `1min` or `15sec`). Where a legacy Fortran `TAG` already selects high-resolution data, preserve that meaning; rename locals only to remove ambiguity. Do not change algorithms, binary layouts, existing map data, or `gosh/` scripts. The decision supports clearer paired product names and prevents confusion between the runoff-grid identity and the map resolution.

## Implementation status

The v5 parameter wrappers and shared generators use the paired naming convention and distinct `HIRES_TAG`. Selected legacy `map/src/src_param/` shell templates were temporarily updated to derive the pair, then restored to their original v4 versions after the maintainer clarified the preservation policy. Existing `diminfo_` files remain available; the CTL generator retains legacy descriptor lookup. No binary map contents were changed.

At the time of the ROFFTAG task, a proposed edit to the legacy `map/src/src_region/` workflow and `s03-mpi_map_setup.sh` was rejected by automatic review. No workaround was attempted. The maintainer later clarified that these files are historical v4 workflows and should remain legacy; their old descriptor names are intentional, not pending migration.

## Later maintainer clarification

The maintainer clarified that `map/src/` is the historical v4 tool tree and should be preserved as legacy. Its old `diminfo_` names are intentional, not pending v5 migrations. New v5 work belongs under `map/tools/`. The six `src_param` shell templates temporarily changed during the ROFFTAG task were restored to their original v4 versions. See `DR-0019`.

## Validation and limits

The map-tools suite passed 29 tests with one existing optional skip. A focused 21-test selection passed. Shell syntax checks passed for the selected wrappers. In a temporary Mekong workspace, the legacy and v5 general input-matrix programs generated byte-identical 1,152,000-byte matrices and identical 11-line metadata when given the same inputs, changing only the descriptor filename. This establishes compatibility for that implementation, compiler, and sample; it is not a full simulation or scientific validation.
