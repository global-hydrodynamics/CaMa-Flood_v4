# DR-0042: Distinguish subbasin background and label sample analysis outputs

## Question and context

The previous subbasin product used nonpositive values for both unassigned small basins and cells outside the modeled river network. The 50,000 km2 example was also not the desired threshold for the Mekong sample, and generic output names did not record the selected GRDC station.

## Evidence examined

- V5 and legacy implementations: `map/tools/code/analysis_get_subbasin.F90`, `map/src/src_param/get_subbasin.F90`.
- Map-local workflows: `map/tools/script_params/s06-subbasin.sh`, `map/mekong_15min/script_params/s06-subbasin.sh`, and `s07-upbasin.sh`.
- Mekong map dimensions, network sentinel values, GRDC allocation table, prior generated outputs, and registry-driven CTL generation.

## Alternatives discussed

- Use zero for both outside-network cells and small subbasins, leaving their interpretation ambiguous.
- Use ID 0 for modeled network cells below the segmentation threshold and retain -9999 for cells outside the network.
- Give every output a generic name, or label the Mekong sample output with its threshold/station identity while retaining generic defaults in the reusable tools.

## Proposal (not yet a decision)

No unapproved proposal remains in this discussion.

## Maintainer decision and rationale

The maintainer directed that threshold-below small modeled subbasins use ID 0 so they remain distinguishable from undefined/sea cells. The Mekong sample uses a 30,000 km2 threshold; this is a sample setting, not a universal scientific calibration. Run the generic subbasin calculation and rename its sample raster to `subbsn-30000.bin`. The reusable v5 template retains its generic 50,000 km2 example and `subbsn.bin` output. The GRDC mask output is station-labeled `upbasin-<GRDC_ID>.bin`; Mekong's selected ID is 2569002. The existing `map/src/` legacy source remains unchanged.

## Implementation instruction

Update the v5 output sentinel handling, Mekong scripts, registry, documentation, and validation. Add exact registry rows for the concrete Mekong filenames. Preserve all existing `workflow_stage` values; the maintainer controls that column manually.

## Outcome or unresolved questions

The v5 sample now uses -9999 outside the modeled network, zero for modeled network cells assigned to below-threshold basins, and positive segment IDs. The Mekong sample wrappers label outputs by threshold and station. Regression at the 30,000 km2 threshold exposed an abort in the legacy program under GNU Fortran 14.2; legacy code was not modified. Its cause and whether legacy users need a fix remain open in KG-0018. A prior set of generic generated sample products was visible at task start but absent when backup was attempted, so their original bytes could not be retained; this is disclosed in the task completion report.
