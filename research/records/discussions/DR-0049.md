## Question and context

The maintainer requested registration of the lab's commonly used ERA5-Land product and global download/conversion scripts under `inp/download_ERA5/`.

## Evidence examined

The CDS ERA5-Land product metadata describes a global 0.1-degree hourly dataset from 1950 to present. The local read-only `inp/ERA5_land/Roff/` link contains daily files from 1981-01-01 through 2020-12-31. Their sizes imply 3,600×1,800 float32 values. Legacy map input-matrix settings specify global 0.1-degree N-to-S geometry; the laboratory run settings use `IFRQ_INP=24` and `DROFUNIT=86400` for `m/day` values. No dedicated CTL or source header was present for this local directory.

## Alternatives discussed

The standard ERA5 atmospheric product and ERA5-Land were distinguished; the existing code requests only ERA5-Land. The new acquisition scripts keep the present conversion rules and reuse the existing ERA5-Land downloader/converter rather than introducing another scientific transformation.

## Proposal (not yet a decision)

Use the existing ERA5-Land runoff download/conversion path with global monthly requests and month-at-a-time binary conversion. Keep the separately linked historical lab product clearly distinguished from new CDS-derived outputs.

## Maintainer decision and rationale

The maintainer directly requested a global ERA5 download-and-processing workflow and registry organization in the active task. This authorization is limited to `inp/download_ERA5/`, runoff registry/documentation, and related research records; it does not authorize changing numerical conversion behavior or modifying the linked source data.

## Implementation instruction, if any

Add global download/conversion entry points, document their settings and verification limits, and register the linked lab series without presenting unresolved metadata as verified.

## Outcome or unresolved questions

Global profiles and documentation are added. The linked product's missing-value encoding, longitude origin, binary provenance, and scientific validity remain unresolved (KG-0024). No CDS request or bulk conversion was run.


## Directory naming follow-up — 2026-11-02

The workflow directory has since been renamed from inp/download_ERA5/ to inp/download_ERA5-Land/ to identify its ERA5-Land runoff scope and distinguish it from general ERA5. The original path references above describe the task context at the time; current files and active links use the new path.
