## Question and context

The MPI preparation wrapper created numbered `mpireg-N.bin` maps and also copied the configured default map to `mpireg.bin`. The alias did not identify its partition count. The user asked for the alias to stop being written, for a default-count `bsncol_mpi-N.bin` output, and for partition connectivity analysis to run on the numbered default map.

## Evidence examined

- v5 `s04-mpi_map_setup.sh` and `param_mpi_set_region.F90`.
- Model runtime map selection in `src/cmf_ctrl_maps_mod.F90` and an existing MPI sample workflow that names `mpireg-${MPINP}.bin`.
- Legacy MPI basin-color output in `map/src/src_param/set_bif_basin_mpi.F90`.
- Current v5 basin display-color implementation in `map/tools/code/param_bif_set_basin.F90`.

## Alternatives discussed

No alternatives were requested.

## Proposal (not yet a decision)

None.

## Maintainer decision and rationale

The maintainer directed that only self-identifying `mpireg-N.bin` files be emitted; the default MPI count should additionally produce `bsncol_mpi-N.bin`; and `analysis_check_mpi_bifurcation` should analyze the numbered default region map. The rationale is to keep the processor-count identity visible in the output filename.

## Implementation instruction, if any

Apply this to the v5 shared and Mekong s04 scripts and their shared Fortran tool, tests, registry, and relevant documentation. Preserve legacy `map/src/` code and do not change model algorithms.

## Outcome or unresolved questions

The wrapper no longer creates `mpireg.bin`. `param_mpi_set_region` writes the basin display-color raster only when called with `write_bsncol`, which s04 supplies only for `DEFAULT_MPI`. The wrapper invokes the independent connectivity analysis on `mpireg-$DEFAULT_MPI.bin`. Focused tests passed, including exact output comparison to legacy `bifcol_mpi.bin` in normal and MaxMPI fixtures. An existing edited `map/mekong_15min/mpireg.ctl` still references the unnumbered name and was left untouched as pre-existing maintainer work; review whether to retarget it to a numbered map.
