## Question and context

Comments in the shared v5 `param_set_bif_basin.F90` described basin merging and visualization as MPI-specific, conflated the two merge stages, and incorrectly claimed that a decreasing loop index reads the sequential file backwards. The maintainer clarified that this is a general map-preparation operation; MPI-specific processing is a separate later workflow.

## Evidence examined

- `param_set_bif_basin.F90` STEP 1 skips paths unless `wth(1)>0`, then merges river-channel-connected basin IDs.
- STEP 2 reads all rows of `bifprm.txt` and merges remaining endpoint basins without a water-level or active-connection condition.
- The STEP 2 loop index decreases, while formatted sequential reads still consume records in their file order.
- Both merge stages select the numerically smaller basin ID as the representative; they do not select by basin area or hydrological dominance.
- `bpoint.bin` stores endpoint status codes; `bifmod.bin` records unchanged/absorbed/expanded status; `bifcol.bin` stores visualization colors.
- The current `set_bif_basin_mpi.F90` starts from `basin.bin`, while `set_mpi_region.F90` reads `bifbsn_mpi.bin`. A source search did not find a direct read of ordinary `bifbsn.bin` by those MPI programs.

## Alternatives discussed

Keep the generic map-preparation operation mislabeled as MPI-specific; or describe its two general connectivity stages and reserve MPI language for downstream use. The task approved the latter and requested that the intended later relationship to MPI domain decomposition remain clear.

## Maintainer decision and rationale

The basin merge is a general map-preparation operation. It first merges river-channel bifurcations identified by positive first-layer width, then includes the other pathways registered in `bifprm.txt`, including floodplain/overland connections. This represents potential connectivity and does not depend on instantaneous water levels. MPI-specific processing remains separate. The output `bifbsn.bin` is identified by the maintainer workflow as relevant to later MPI domain work; visualization colors and endpoint diagnostics are not MPI partitions.

## Implementation instruction, if any

Revise comments only in `map/tools/code/param_set_bif_basin.F90`; do not change executable statements, algorithms, output formats, scripts, or legacy files. Correct documentation if it misidentifies the output maps as model inputs. Record the clarification and validate the research records.
