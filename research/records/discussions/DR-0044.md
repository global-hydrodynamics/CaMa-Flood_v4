## Findings and proposed work

The repository download path is ERA5-Land-specific. The converters assume accumulated metres, difference within UTC calendar dates, convert to millimetres, and write NetCDF or daily-file binary products. The current repository has raw and converted NetCDF examples but not the binary records named by its tracked CTL and configuration report. The model derives runoff depth rate through `DROFUNIT`; input-matrix area weights then provide discharge. The annual-mean runoff channel workflow is separate and consumes a one-record climatology in mm/s.

The Phase A report proposes a focused dataset registry, synthetic converter fixtures, separate model-contract tests, and staged work for metadata, ERA5-Land conversion, samples/tests, and mean-runoff/channel integration. These are proposals, not implementation approvals. The registry schema and choice of any added real or binary samples remain undecided.

## Knowledge-gap review

The substantial-task review found a material time-label question: the downloader requests ERA5-Land times beginning at 00:00; official documentation says a CDS valid time of 00:00 represents the preceding day's 24-hour accumulation; current converters group by calendar date and retain the first accumulated value as the day's first increment. This is recorded in KG-0019. It matters before changing conversion semantics but does not prevent inventory completion or preparation of synthetic fixtures.

Other unresolved questions, including negative-difference handling, exact climatology statistics, registry row granularity, sample redistribution scope, and PR #120 acceptance ownership, are grouped in [`docs/runoff_data_inventory.md`](../../../docs/runoff_data_inventory.md#questions-for-maintainer-review). No scientific interpretation was silently selected.
