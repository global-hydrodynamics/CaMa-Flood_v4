## Approved scope and decisions

The task authorizes migration of MPI map preprocessing into the existing v5 `map/tools/` architecture while preserving the historical `map/src/` and `gosh/` trees. Ordinary `bifprm.txt` is the shared standard/MPI input and must remain byte-for-byte unchanged. MPI basin merging uses the existing normal 6%, `MaxMPI` 3%, and 0.1% small-basin thresholds and existing region assignment algorithm. Permanent products are limited to `mpireg-N.bin` and selected `mpireg.bin`; basin groups may be temporary, and MPI-specific pathway tables and legacy diagnostic rasters are not standard v5 outputs. The wrapper reports connectivity for the selected default partition; a separate analysis wrapper can inspect arbitrary compatible region maps and optionally export dropped pathways. No merge, force-push, numerical threshold change, ordinary s02 calculation change, or legacy-tree edit is authorized.

The task instruction records the original developer's confirmation that the legacy shell sort was deliberately added to give deterministic pathway-processing order. Therefore, sorting by the actual parsed values `ibsn`, `jbsn`, then `elv` is part of the intended order-sensitive algorithm. The legacy shell keys (`sort -n -k 15n -k 16n -k 6n`) depend on `BIFLAYER` because the basin-ID columns move. The v5 implementation moves the sort into the Fortran aggregation program, uses parsed fields, does not rewrite the source table, and uses source-row text only as a deterministic equal-key fallback. The fallback is tested for repeatability and agrees with Mekong legacy outputs; it is not presented as an additional scientific priority.

## Verified implementation and source findings

The v5 wrapper reads the ordinary `bifprm.txt`, creates a temporary MPI basin-group raster, generates the requested region maps, aliases the configured default to `mpireg.bin`, confirms the standard pathway file did not change, removes the temporary raster, and runs the independent report for the default. The independent analyzer reproduces the endpoint-vector construction relevant to `READ_BIFPARAM`: `CALC_1D_SEQ` begins with cells assigned to a region and its downstream traversal can append a downstream endpoint without rechecking its region label. This is a specific downstream vector extension observed in the source, not evidence of a general ghost-cell exchange system. Synthetic coverage demonstrates that a pair crossing assigned labels can still coexist in a local model vector.

Legacy and v5 normal and `MaxMPI` basin-group rasters and each 4/8/16 region map matched byte-for-byte on the inspected Mekong sample. On the normal default 16-region map, the analyzer found 382 pathways: 355 retained, 27 dropped, 0 invalid (7.0681%). On the `MaxMPI` 16-region map it found 339 retained, 43 dropped, 0 invalid (11.2565%). Neither sample's retained set required cross-label downstream extension. These counts describe pathway availability under the partition; they do not quantify hydraulic simulation error.

The old MPI workflow also emits partition-specific pathway tables and diagnostic arrays. Source review showed that the v5 map-preparation dataflow can use temporary basin groups and does not need to retain those tables/diagnostics as map products. The independent analysis consumes the ordinary pathway table and any compatible region raster, avoiding dependence on legacy partition-specific lists.
