## Decision and rationale

The maintainer approved merging the previously proposed `script_allocate/` shell family into `script_params/`. Flow-gauge, level-gauge, and dam location allocation are part of preparing a map, which commonly includes parameterization and related setup. Keeping these recipes together makes the map-preparation workflow easier to discover.

The target shell-script families are: `script_region/` for regional map generation; `script_params/` for channel parameterization, runoff input matrices, bifurcation/MPI setup, and gauge/dam allocation; and `script_analysis/` for independent analysis and diagnostics. All Fortran source files and compiled executables remain centralized in `map/tools/code/`. Useful executable family prefixes remain `region_*`, `param_*`, `analysis_*`, and `allocate_*`; executable naming does not dictate a separate script directory.

## Constraints and scope

This is an approved organizational decision for migration planning. It does not start implementation, authorize scientific or interface changes, or authorize changes to the legacy tools under `map/src/`. Do not create `map/tools/script_allocate/`. The Python dam-parameter estimation workflow under legacy `map/src/src_dam/` remains distinct from the Fortran `allocate_dam` location-allocation utility; where a future v5 recipe for that Python workflow belongs remains open.

## Documentation outcome

Updated `docs/map_params_migration_plan.md`, `map/tools/README.md`, and `map/tools/script_params/README.md` to describe the approved families, central executable location, and distinction between allocation and parameter estimation. No code or legacy tool changed.
