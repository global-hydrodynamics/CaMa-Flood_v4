## Question and context

The legacy v4 parameter scripts combine standard bifurcation processing with MPI preparation. The v5 migration needed a clear boundary so that the standard workflow could be reused without silently changing bifurcation ordering or making MPI-specific changes.

## Evidence examined

- Legacy sources: `map/src/src_param/set_bifparam.F90`, `map/src/src_param/set_bif_basin.F90`, `map/src/src_param/set_bif_basin_mpi.F90`, and `map/src/src_param/set_mpi_region.F90`.
- Legacy workflow: `map/src/src_param/s01-channel_params.sh` and `map/src/src_param/s03-mpi_map_setup.sh`.
- Shared build and wrapper patterns: `map/tools/code/Makefile`, `map/tools/script_params/s01-channel_params.sh`, and `map/tools/script_params/s03-generate_inpmat.sh`.
- Maintainer-approved Phase B2.3 task instruction and project Issue #122.

## Alternatives discussed

The legacy combined workflow could have been copied as one sequence, including sorting and MPI-specific basin products, or the standard and MPI processing could have been split. The task instruction approved the split; no alternative MPI behavior was selected for implementation in this phase.

## Proposal (not yet a decision)

No proposal remains for the standard workflow boundary. Details of the future MPI `s04` implementation and its output regression remain deferred.

## Maintainer decision and rationale

The standard non-MPI bifurcation workflow belongs in `s02-bifurcation.sh`, after channel depth is available from `s01`. It generates ordinary hydraulic bifurcation parameters and ordinary basin-connectivity products, preserving the legacy scientific behavior and the unsorted `set_bifparam` output order. `BIFLAYER` remains 5; the documented maximum remains 10.

MPI-specific sorting, `set_bif_basin_mpi`, `set_mpi_region`, MPI products, and `MaxMPI` handling belong exclusively to the separate `s04-mpi_map_setup.sh`. The legacy sort recipe remains MPI-specific. This separation prevents MPI preparation from modifying the standard bifurcation products and makes the standard workflow usable independently of an MPI partitioning choice.

All shared Fortran sources/executables remain under `map/tools/code/`, with the existing shared Makefile. Map-local wrappers remain under `map/tools/script_params/`. The original v4 implementations under `map/src/` and execution scripts under `gosh/` remain unchanged. Numerical algorithms, binary/text layouts, special values, and output filenames are not changed by this migration.

## Implementation instruction, if any

Copy the two ordinary programs into shared `param_*` sources with only the executable program-unit names changed, and add a map-local `s02-bifurcation.sh`. The wrapper must run `param_set_bifparam` from map-root CWD and `param_set_bif_basin` from the map-local `script_params/` directory because their relative path assumptions differ. It must retain legacy overwrite behavior and must not run MPI-specific operations.

## Outcome or unresolved questions

Implementation and temporary Mekong regression results are recorded separately in `EV-0094`, `EV-0095`, and `VR-0029`. The successful regression does not establish independent scientific correctness. Migration of the MPI workflow remains deferred.
