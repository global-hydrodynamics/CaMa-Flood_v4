## Confirmed design decisions

- Tutorial 02 compares four cases: Default, No Bifurcation, Kinematic Wave, and No Floodplain.
- `DT=600` seconds is common. Adaptive stepping is enabled for both Local Inertial cases and disabled for both Kinematic Wave cases.
- Bifurcation is enabled only in Default. No Bifurcation isolates that option within Local Inertial routing; the Kinematic Wave cases remain bifurcation-off because the current source rejects Kinematic Wave with bifurcation enabled.
- The tutorial retains its 2000–2003 simulation, annual NetCDF runoff/output/Restart, daily mean `outflw`, GRDC model locations without observed discharge, and Default-only spin-up visualization.
- Annual maximum daily-mean `outflw` maps for 2001–2003 are added as a spatial comparison across all four experiments. The output timestamps mark interval ends, so each daily record must be assigned to the year of its represented interval.
- GitHub should retain four experiment scripts; the beginner package includes only Default and excludes the other scripts during package assembly.

## Workflow decision

Future tutorial work must include interactive scientific review after source/data investigation and before specification approval. Source inspection establishes technical facts and feasible options; the researcher makes scientific design decisions. Execution results may require revising the specification. The specification is version-controlled and may evolve through repeated review.
