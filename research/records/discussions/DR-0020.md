## Confirmed registry meaning

The maintainer added `sub_id=C` to the four variables in the v5 bifurcation check-only files `check_bif_bsnmod.bin` and `check_bif_dphwth.bin`. In this use, C identifies optional outputs that are not emitted unless explicitly requested. The inspected v5 wrapper uses the `check_map` argument to request these diagnostic files. The label records output selection; it does not mean that these products are model runtime inputs. The distinct `runtime_requirement` field continues to describe runtime use.

The maintainer also reported manually running the Mekong map script and refreshing its data. The particular command, exact generated file inventory, and code revision used for that manual run were not provided. Record this as maintainer-reported sample preparation, not as reproducible test evidence or scientific validation.
