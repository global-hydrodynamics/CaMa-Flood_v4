## Context

The earlier `prmwat` migration recorded the `flddif` threshold but did not know its scientific purpose. The maintainer clarified why high-resolution permanent-water pixels are filtered by relative elevation.

## Confirmed scientific rationale

`prmwat` should describe permanent water within the inundation area CaMa-Flood can reproduce. Isolated permanent lakes high on hills are outside the model's expected inundation domain, so they must not be included in `prmwat` and subtracted as pre-existing simulated floodwater when estimating new inundation.

The maintainer described the intended condition as `flddif < 5 m`. The existing v4 source and migrated v5 implementation use `flddif <= 5 m`, which includes pixels at exactly 5 m. This task requested documentation of the rationale and did not authorize a numerical behavior change. The source therefore remains unchanged; the inclusive/exclusive boundary is separately tracked as KG-0011.

## Implementation and evidence

The v5 source comments, shared and Mekong parameter READMEs, map metadata specification, and `prmwat` registry now explain the model-representable inundation rationale and state both the maintainer-described criterion and actual comparator. No algorithm or test behavior was changed. See `map/tools/code/param_water_calc_prmwat.F90`, `map/tools/script_params/README.md`, `map/mekong_15min/script_params/README.md`, `map/map_metadata_spec.md`, and `map/map_variables.csv`.

The physical rationale for the filter is now documented. The numerical derivation of the 5 m cutoff remains unknown (KG-0009), and whether values exactly equal to 5 m should be included requires maintainer confirmation (KG-0011).
