## Confirmed workflow requirement

The maintainer clarified that the `inpmat` produced by `s02-generate_inpmat.sh` is needed for a later sample simulation. The generated matrix is therefore a prerequisite for that future sample run, in addition to being a user-configurable map-to-runoff-grid product. This does not make it interchangeable with the standard matrix produced by `region_default_inpmat`.

## Deferred choice

The sample map/runoff product has not been selected. Which data should be committed to the GitHub repository and which should be included in the downloadable package will be considered later, based on the data needed for the sample and what each distribution route can carry. This choice affects sample reproducibility and the required matrix configuration. Until that decision is made, retain the current example settings as an example only and do not add sample data or treat those settings as the sample-simulation specification.

## Documentation outcome

Added this dependency and the deferred data-selection question to `map/tools/script_params/README.md` and `docs/map_params_migration_plan.md`. No source, numerical behavior, or dataset was changed.
