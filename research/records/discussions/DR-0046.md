## Context and authorization

The maintainer clarified that internal `ELSE_GPCC/Roff/` is the global 1-degree runoff product associated with Kim et al. (2009), and that package sample `test_1deg/` is a two-year extraction. The requested Mekong sample uses the existing 90–110°E, 5–35°N domain for 1980–2010. The extraction script and documentation are to be version-controlled; generated runoff binaries are not to be pushed while redistribution permission remains uncertain.

## Evidence and implementation

The source CTL declares a 360×180, 1-degree, little-endian float32 grid in north-to-south row order, runoff in mm/day, and -999 undefined. Local source filenames cover the requested dates even though the source CTL time declaration is inconsistent with available files. The implementation records this discrepancy and validates filename coverage directly.

The in-directory shell entry point calls a Python standard-library helper. The helper crops the requested 20×30 window by byte slices and validates every source/output size and exact selected-byte equality. It generates a regional daily GrADS CTL and performs metadata checks. The source directory is opened read-only; output binaries are ignored by Git pending review.

## Limits

The exact byte comparison proves the selected source values were copied without numerical transformation; it does not independently validate the scientific product or its suitability for a simulation. The Kim et al. citation documents the maintainer-provided provenance but does not establish redistribution rights. No model simulation was run. The eartH2Observe WRR2 sample's exact acquisition URL/publication remains unresolved as documented separately in the inventory.
