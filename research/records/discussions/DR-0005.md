# DR-0005: Clarify and rename the standard regional input-matrix generator

## Question and context

The v5 regionalization utility was named `region_generate_inpmat`, which did not distinguish it from the general-purpose legacy `src_param/generate_inpmat` and could imply a generic user-configurable input-matrix interface.

## Evidence examined

The v5 program accepts a high-resolution tag and uses fixed settings for the standard 1-degree global north-to-south runoff-climatology mapping matrix and paired `diminfo_test-1deg.txt`. The legacy `map/src/src_param/generate_inpmat.F90` exposes user-selected grid geometry and output paths. The regional tool is built and called as part of the `region_*` regional map workflow. See `map/tools/code/region_default_inpmat.F90`, the regional wrappers, and the registry rows for `inpmat_test-1deg.bin` and `diminfo_test-1deg.txt`.

## Alternatives discussed

No algorithm consolidation was proposed. The general-purpose utility remains a separate future `param_generate_inpmat` candidate; the v5 regional utility keeps the `region_*` family name.

## Proposal (not yet a decision)

The rename was initially proposed as a naming-only clarification: source/executable `region_default_inpmat`, with arguments, CWD, data processing, binary layout, precision, output names, and execution order unchanged.

## Maintainer decision and rationale

The maintainer approved this clarification. The regional utility produces the standard map-supported input mapping used with the annual runoff climatology for channel cross-section parameter estimation, so it belongs to regional map preparation and the `region_*` family. The new `default` name distinguishes this fixed standard product from the general configurable `param_generate_inpmat`. The two implementations must not be merged or treated as interchangeable.

## Implementation instruction, if any

Rename the v5 source and executable, update shared build/workflow references and documentation, preserve category IDs, and do not modify legacy v4 sources or regenerate sample maps. This approval does not authorize numerical, interface, data-format, or broader migration changes.

## Outcome or unresolved questions

The source and executable were renamed, regional scripts and documentation were updated, and the matrix plus paired metadata were described as standard distributed supporting products. The registry category IDs were preserved. Validation evidence is in `VR-0023`. No numerical algorithm or committed map binary/CTL was changed.
