## Source-grounded findings

- `CMF_CONFIG_CHECK` stops when Kinematic Wave and bifurcation routing are both enabled. It recommends a fixed timestep for Kinematic Wave and warns that adaptive timestep is recommended only with Local Inertial routing.
- A common `LPTHOUT=.FALSE.`, `LADPSTP=.FALSE.`, `DT=3600` configuration keeps the three requested comparisons executable and more controlled, but disabling bifurcation also changes the existing `mek01` reference configuration. The choice is therefore documented as a maintainer decision, not silently assumed approved.
- `LFPLAIN` and `LFLDOUT` are separate controls. `LFPLAIN=.FALSE.` changes initialized river storage capacity; Kinematic routing separately supports floodplain outflow through `LFLDOUT`.
- A no-Restart start does not guarantee an all-zero water state: `CMF_PROG_INIT` zeros prognostic arrays and then `STORAGE_SEA_SURFACE` fills channel storage to respect the downstream boundary water level.
- Annual NetCDF runoff uses `CROFFREQ="YEAR"`, CF-time validation, and `DROFUNIT`; the matching input matrix remains the existing Binary map-specific matrix.
- `outflw` is written from its time-average diagnostic array, as float32 NetCDF, with time labels at the end of each averaging interval.
- Valid Mekong GRDC station locations exist. Five candidates are recorded, but final site suitability for a floodplain-learning objective remains to be reviewed.
- Only the 2000 and 2001 annual NetCDF runoff files are tracked. Local 2002 and 2003 files were untracked and were not accepted as clean-checkout reproducible inputs.
