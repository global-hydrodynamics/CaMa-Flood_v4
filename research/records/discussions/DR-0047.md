## Authorization and provenance

The maintainer requested a compact 6-arcmin hourly sample derived from local `inp/test_jpn_1hr/`, confirmed that the 1-arcmin simulation output came from the Today's Japan system and was provided by Yoshimura Laboratory, and confirmed redistribution permission. The original large source must remain excluded and unchanged; outputs are generated under `inp/test_jpn_6min_1hr/`. The task explicitly prohibits pushing changes before maintainer review.

## Method and validation boundary

The workflow area-weights each 6×6 group using latitude-dependent spherical cell areas, retains the hourly records and raw units/values, and writes north-to-south little-endian float32 daily files. The original source CTL says `mm/day`; the maintainer subsequently identified that label as erroneous and assesses the values as `mm/hour`, consistent with the existing hourly `DROFUNIT=3600000` convention. The derived CTL and registry now use `mm/hour`; this interpretation is not independently confirmed by source-product documentation. See VR-0076 for format, conservation, and scalar block-check results.

No input matrix or model simulation was run. Numerical conservation validates the spatial transform and binary layout, not the scientific validity of the source runoff.
