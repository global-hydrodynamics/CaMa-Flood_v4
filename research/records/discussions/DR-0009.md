## Approved v5 interface

For the new v5 channel-parameter workflow, use the shared source/executable name `param_set_merit_width` and write the alternate width product as `rivwth_merit.bin`. Retain `width.bin` as the MERIT Hydro width input, and retain `rivwth.bin` and `rivhgt.bin` as the power-law-derived width and depth products. Keep the width-merging algorithm and its thresholds unchanged.

## Compatibility boundary

All legacy scripts under `gosh/` and `map/src/` remain unchanged. In particular, legacy `map/src/src_param/set_gwdlr.F90` and its workflow continue to use `rivwth_gwdlr.bin`; the old registry row is retained separately from the v5 `rivwth_merit.bin` row. This is an approved v5 filename/interface change, not approval for a numerical algorithm change, core-reader change, or wider compatibility break.

The v5 shared utility is not automatically selected by the current core map reader, which expects `rivwth.bin`. No v5 channel orchestration wrapper existed for this change; workflow integration and reader selection remain separate future work.

## Validation boundary

The migrated source was compared with the legacy program on synthetic inputs; see `VR-0027`. Byte-identical output in that fixture supports preservation of the tested algorithm, but is not scientific validation or proof across all datasets and compilers.
