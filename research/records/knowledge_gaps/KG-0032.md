# KG-0032: Shared bifurcation setting for Tutorial 02 comparisons

- Gap ID: KG-0032
- Linked event ID(s): EV-0383
- Category: scientific configuration / compatibility
- Evidence basis: source-code evidence plus unresolved maintainer decision
- Status: open

## What was unknown or assumed?

Should all three Tutorial 02 experiments use `LPTHOUT=.FALSE.` so the Kinematic Wave cases can run and bifurcation remains a common control? This would differ from `gosh_sample/mek01-default_run.sh`, which enables bifurcation.

## How was it discovered?

During source review of the requested experiment matrix. `src_main/cmf_ctrl_nmlist_mod.F90`, `CMF_CONFIG_CHECK`, issues a fatal stop when `LKINE` and `LPTHOUT` are both true and reports that bifurcation channel flow is available only with Local Inertial routing. This matters because the intended Kinematic Wave and No Floodplain cases both set `LKINE=.TRUE.` while the referenced Mekong `mek01` sample enables `LPTHOUT`.

## Verified facts

- The current model rejects `LKINE=.TRUE.` with `LPTHOUT=.TRUE.` during configuration.
- Setting bifurcation false for all three allows the intended comparison matrix to use a shared value for this option.
- Whether disabling bifurcation is scientifically acceptable for the Local-inertial reference is not determined by source compatibility alone.

## How was the knowledge formalized?

The compatibility requirement, proposed common setting, and alternative need for a redesigned experiment are stated in `tutorial/tutorial02-mekong_netcdf_3exp/experiment_spec.md`.

## Why the gap matters

The setting controls an established flow-routing feature and may affect discharge at the comparison locations. The three experiments should share it for interpretation, but selecting its value changes what the “Default” reference represents. Script implementation should wait for this decision; unrelated tutorial documentation work can continue.
