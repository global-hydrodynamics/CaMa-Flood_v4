# KG-0032: Shared bifurcation setting for Tutorial 02 comparisons

- Gap ID: KG-0032
- Linked event ID(s): EV-0383; EV-0385
- Category: scientific configuration / compatibility
- Evidence basis: maintainer-confirmed design decision plus source-code compatibility checks
- Status: resolved by maintainer-approved redesign

## What was unknown or assumed?

The initial three-experiment proposal could not include Kinematic Wave while retaining bifurcation. The maintainer resolved this by adding a separate No Bifurcation experiment, retaining bifurcation in Default, and disabling it for both Kinematic Wave cases.

## How was it discovered?

During source review of the requested experiment matrix. `src_main/cmf_ctrl_nmlist_mod.F90`, `CMF_CONFIG_CHECK`, issues a fatal stop when `LKINE` and `LPTHOUT` are both true and reports that bifurcation channel flow is available only with Local Inertial routing. This matters because the intended Kinematic Wave and No Floodplain cases both set `LKINE=.TRUE.` while the referenced Mekong `mek01` sample enables `LPTHOUT`.

## Verified facts

- The current model rejects `LKINE=.TRUE.` with `LPTHOUT=.TRUE.` during configuration.
- The four experiments use `LPTHOUT=.TRUE.` only for Default and `.FALSE.` for No Bifurcation, Kinematic Wave, and No Floodplain.
- Kinematic Wave requires `LPTHOUT=.FALSE.` in the current source; the new experiment isolates the bifurcation setting within Local Inertial routing.
- The maintainer approved `DT=600`, adaptive stepping for both Local Inertial experiments, and fixed stepping for both Kinematic Wave experiments.

## How was the knowledge formalized?

The resolved design and comparison interpretation are stated in `tutorial/tutorial02-mekong_netcdf_4exp/tutorial_design.md`.

## Resolution trace

- Resolution method: maintainer-confirmed experiment redesign, checked against current model configuration constraints.
- Evidence or maintainer explanation: the maintainer approved four configurations so the Local Inertial bifurcation effect is compared separately, while Kinematic Wave remains bifurcation-off.
- Final interpretation and rationale: retain bifurcation in Default; add No Bifurcation as its controlled Local Inertial counterpart; keep bifurcation off for Kinematic Wave cases because that combination is unsupported.
- Formalization location(s): `tutorial/tutorial02-mekong_netcdf_4exp/tutorial_design.md`, Sections 2 and Appendix A.
- Human review: decision supplied in the maintainer-approved task; runtime validation remains pending.

## Verification and limits

No simulation was run for the four-experiment design. The decision resolves the experiment-design gap, not the runtime or scientific validation of resulting comparisons.

## Why the gap matters

The setting controls an established flow-routing feature and may affect discharge at the comparison locations. The four-case design now separates its effect within Local Inertial routing while respecting the source limitation for Kinematic Wave. Implementation and results still require a separate validated stage.
