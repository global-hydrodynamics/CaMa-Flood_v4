# KG-0004: Existing map registry roles conflict with observed processing use

- Gap ID: `KG-0004`
- Linked event ID(s): `EV-0099`
- Category: metadata semantics / classification conflict
- Evidence basis: Existing maintainer-assigned sub_id values plus repository source/configuration evidence
- Status: open

## What was unknown or assumed?

The registry contained A assignments for several products that the current usage/runtime notes and source paths identify as preprocessing products. The task required preserving those assignments, so the code review did not resolve their final labels. A separate review also found stale runtime metadata for input matrices that are in fact configured for model execution; those descriptions were corrected with source and run-script evidence.

## How was it discovered?

The approved `sub_id` policy defines A as model-execution input and B as preparation/diagnostic/analysis data. Inspection found existing A rows for derived regional-grid products and no-edge preprocessing maps. In contrast, `inpmat_test-1deg.bin` and `diminfo_test-1deg.txt` are selected in `gosh/test1-glb_15min.sh` and consumed by the model input-configuration path, so their A labels are supported; the stale “preprocessing only” metadata was corrected. The registry entries and source references are retained in `map/map_variables.csv`.

## Verified facts

- `nxtdst_grid.bin` and `rivlen_grid.bin` are used by regional preprocessing/analysis, not the core runtime map reader (`map/src/src_region/set_map.F90`).
- `grdare.bin` is referenced by regional/high-resolution preprocessing workflows; no core runtime reader is listed for this row (`map/src/src_region/cut_domain.F90`, `set_map.F90`, and `generate_inpmat.F90`).
- `nextxy_noedge.bin` is read by regional/bifurcation preprocessing (`map/src/src_region/cut_domain.F90`, `cut_bifway.F90`).
- The conflicting existing A rows are `nxtdst_grid.bin`, `rivlen_grid.bin`, `grdare.bin`, and both variable rows of `nextxy_noedge.bin`. Their recorded/source-traced use is preprocessing or analysis, not a supported model input. The maintainer must decide whether they should be B or whether an external runtime use justifies A.
- These five A row values predated this task and were preserved as instructed. The apparent conflict remains open until the maintainer decides whether to reclassify them or confirms an additional supported runtime use.

## How was the knowledge formalized?

The distinction and conflict-handling rule are defined in [`map/map_metadata_spec.md`](../../../variable_table/map_metadata_spec.md). Final role changes for the preprocessing products below require a maintainer decision.

## Verification and limits

Registry validation, CTL-generator unit tests, and research-record validation are recorded in `VR-0031`. This gap concerns classification consistency, not model numerical behavior. Repository evidence may not establish every external or unpublished workflow; maintainer confirmation is needed before changing preserved values.

## Why the gap matters

These five rows can make A/B filtering unreliable and could imply that preprocessing products are read by the model. Preserving them avoids silently overriding maintainer edits while exposing the exact review decision.
