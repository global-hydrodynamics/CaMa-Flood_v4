# KG-0029: Binary and NetCDF Restart readers initialize current outflow arrays differently

- Gap ID: `KG-0029`
- Linked event ID(s): `EV-0329`
- Category: Restart input state / numerical continuity
- Evidence basis: source-code inspection and two-year Mekong comparison
- Status: closed (source-level reader alignment; post-fix runtime validation not recorded)

## Initial open question (as recorded at EV-0329)

For a normal Restart, the NetCDF reader copies `rivout_pre` and `fldout_pre` into the current river and floodplain outflow arrays after reading. The Binary reader reads the `_pre` fields but leaves the current arrays at the zero initialization in `CMF_RESTART_INIT`. It is not established whether the current arrays are used before being recalculated after restart, or whether this difference is historical and intentional.

## Discovery trigger and why it matters

While documenting Restart fields and comparing the NetCDF and Binary read paths, inspection of `READ_REST_CDF` and `READ_REST_BIN` in `src_main/cmf_ctrl_restart_mod.F90` exposed the difference. If current outflow arrays are consumed before they are overwritten, restart format could affect the first step after a restart. The tested 2000–2001 Mekong run produced exactly matching `outflw`, `storge`, and `sfcelv` arrays, but that does not establish behavior for every configuration.

## Verified facts at initial discovery

- `CMF_RESTART_INIT` initializes `D2RIVOUT` and `D2FLDOUT` to zero before selecting a format reader.
- `READ_REST_BIN` restores `D2RIVOUT_PRE` and `D2FLDOUT_PRE` but does not assign the current outflow arrays.
- `READ_REST_CDF` restores those `_pre` fields and assigns them to `D2RIVOUT` and `D2FLDOUT`.
- The same Mekong two-year configuration produced bitwise-identical tested output variables under Binary and NetCDF Restart.
- No Restart I/O code was changed in this task.

## Maintainer review requested at initial discovery

Confirm whether the format-specific current-outflow initialization is intentional or should be aligned in a separate approved source task. Before changing it, trace all reads of the current arrays between `CMF_RESTART_INIT` and their first normal calculation, and test the affected restart boundary. Documentation and CTL tooling can proceed independently.

## Formalization

The observed source behavior is described in [`src_main/README.md`](../../../src_main/README.md). The runtime comparison is summarized in the same document and recorded in `VR-0105`.

## Resolution trace

- Resolution method: maintainer-directed source correction, verified by inspection of the pushed diff.
- Evidence: commit `87abfddf` adds `D2RIVOUT=D2RIVOUT_PRE` and `D2FLDOUT=D2FLDOUT_PRE` in the Binary Normal Restart reader; the NetCDF reader already performs the same assignments. The correction follows the maintainer's choice to retain NetCDF initialization and align Binary state.
- Final interpretation and rationale: Normal Restart should initialize current river and floodplain outflows from their restored previous-step values in both formats. This preserves the saved state used for continuation and keeps format-specific diagnostic initialization from diverging.
- Formalization location(s): `src_main/cmf_ctrl_restart_mod.F90`; [`src_main/README.md`](../../../src_main/README.md); [`model_source_workflow_plan.md`](../../../docs/model_source_workflow_plan.md#restart-initialization-review); [`DR-0052`](../discussions/DR-0052.md).
- Human review: the maintainer supplied the decision and implementation; review of this research-summary wording remains pending.

## Verification and limits

The two-year sample in `VR-0105` predates commit `87abfddf`; it is not a runtime validation of the correction or its first-step diagnostic effects. No post-fix model run is recorded here.

## Why the gap mattered

The prior source discrepancy could affect first-step diagnostics even when the selected forecast outputs agree. The source behavior is now aligned; a future focused Restart-boundary regression may verify runtime diagnostics when such a check is scheduled.

## Current verified source state

In the current `feature/gosh-refactor` source, `READ_REST_BIN` and `READ_REST_CDF` both assign restored `D2RIVOUT_PRE` and `D2FLDOUT_PRE` to the corresponding current outflow arrays during Normal Restart. The original Binary/NetCDF difference described above is retained as the discovery history, not as current behavior. The Binary assignment is present in maintainer commit `87abfddf`.
