# KG-0023: ELSE_GPCC source CTL time axis and file coverage

- Gap ID: `KG-0023`
- Discovery event: `EV-0248`
- Category: source CTL temporal coverage / source file inventory
- Status: open
- Evidence basis: Read-only audit of the local source file names and sizes, compared with the tracked `inp/ELSE_GPCC/Roff.ctl`

The CTL declares 7,671 daily records beginning 1981-01-01. The local source directory contains expected-size files for every date from 1979-01-01 through 2010-12-31 (11,688 days), plus a zero-byte file named `Roff____20110101.one`. The reason for this mismatch and the authoritative source time coverage are unknown.

The registry records the observed expected-size daily-file period and flags the configuration for maintainer review. The `1deg_test` generator selects 2000–2001 by date-named files, checks each input size and exact output bytes, and writes a CTL for that selected period. This does not correct the source CTL or establish the source product's complete valid temporal coverage.

References: `inp/ELSE_GPCC/Roff.ctl`, `inp/runoff_datasets.csv`, `inp/1deg_test/README.md`, `docs/runoff_data_inventory.md`, and `VR-0077`.
