# KG-0022: Physical unit and temporal meaning of Japan hourly runoff values

- Gap ID: `KG-0022`
- Linked event ID(s): `EV-0243`, `EV-0246`
- Category: source runoff unit / temporal meaning
- Evidence basis: The original sample CTL labels `mm/day`; the maintainer identifies this label as erroneous and assesses the actual hourly values as `mm/hour`. The available package metadata does not independently confirm the interpretation.
- Status: partially formalized; adopt the maintainer's `mm/hour` assessment in the derived CTL and registry, while retaining the limitation that source-product documentation was not available for independent confirmation

## What is known?

The Japan sample is stored as hourly records. The original `runoff.ctl` incorrectly labels the variable `mm/day`, according to the maintainer's clarification. The maintainer believes the intended unit is `mm/hour`; this agrees with the existing `gosh/test3-jpn_fcast.sh` settings (`IFRQ_INP=1`, `DROFUNIT=3600000`). The divisor is consistent with the assessment but is not, by itself, independent source evidence.

## Remaining uncertainty and impact

No additional Today's Japan product metadata or processing history was available to independently verify the physical unit. The derived binary values have not been changed. The new CTL and registry use `mm/hour` as the maintainer-directed interpretation, and the registry retains `needs_maintainer_review` to avoid overstating independent validation.
