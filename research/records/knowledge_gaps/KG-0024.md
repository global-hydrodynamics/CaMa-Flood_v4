# KG-0024: Metadata of the linked global ERA5-Land binary series

- Gap ID: `KG-0024`
- Linked event ID(s): `EV-0252`
- Category: source product format / scientific assumption
- Evidence basis: package observation / configuration evidence / unresolved
- Status: open

## What was unknown or assumed?

The linked `inp/ERA5_land/Roff/` legacy archive has no dedicated CTL or per-file header and omits the north-south half-grid shift used by the canonical `daily/` geometry. The `daily/` folder currently has only one 1960-01-01 headerless sample. Its missing-value meaning, longitude order, exact upstream processing, and independent confirmation of units and physical daily semantics are unknown.

## How was it discovered?

A read-only inspection found a symlink to a local external product directory. The `Roff/` child contains 14,610 consecutive daily filenames from 1981-01-01 through 2020-12-31. Every file is 25,920,000 bytes, consistent with 3,600×1,800 float32 values. `map/src/src_param/u02_ERA5_sixmin_generate_inpmat.sh` specifies a global 0.1-degree grid with N-to-S order; `etc/levee_params/s05-run_levee.sh` configures 24-hour forcing and `DROFUNIT=86400` (`m/day`). These are workflow/configuration observations, not a source-product header.

## Verified facts

- The link target is local and external to Git; `.gitignore` excludes `inp/ERA5_land`.
- The filenames cover every date from 1981-01-01 through 2020-12-31 (14,610 files), and all files have equal 25,920,000-byte size.
- The size is exactly 3,600×1,800×4 bytes.
- The maintainer confirms `Roff/` is a legacy geometry without the north-south half-grid shift; `daily/` is canonical.
- The only observed `daily/` sample is 25,934,400 bytes, exactly 3,600×1,801×4 bytes. The maintainer identifies 90.05/−90.05 grid limits and 1801 latitude rows as the canonical geometry.
- `map/src/src_param/u02_ERA5_sixmin_generate_inpmat.sh` uses 90/−90 limits for the old 1800-row legacy matrix; `u01_era5_hour_generate_inpmat.sh` uses 90.05/−90.05 for 1801 rows.
- Existing map-input settings use 0.1-degree global bounds and N-to-S ordering; the legacy run script uses `DROFUNIT=86400` and a 24-hour interval.
- No `Roff.ctl` or metadata header accompanies the inspected binary directory.

## How was the knowledge formalized?

The registry row is marked `needs_maintainer_review`; `inp/README.md` and `docs/runoff_data_inventory.md` distinguish the linked product from the new CDS conversion workflow. No scientific conversion code was changed.

Both linked directories were inspected read-only; the `daily/` sample file size and little-endian float32 interpretation were checked without writing to it. ## Why the gap matters

Incorrect longitude origin or missing-value handling would spatially misassign or contaminate runoff input. Incorrect units or daily accumulation semantics would alter the runoff magnitude and time interpretation in a model run.
