# KG-0006: Meaning of the high-resolution `rivwth == -1` class

- Gap ID: `KG-0006`
- Linked event IDs: `EV-0170`, `EV-0171`, `EV-0172`
- Category: scientific/data semantics
- Evidence basis: legacy-source rule plus maintainer-confirmed class meaning
- Status: partially_formalized

## What was unknown or assumed?

The permanent-water source selects both positive `rivwth` values and `-1`, but the class meaning of `-1` was not established by that condition alone.

## How was it discovered?

During migration review of `map/src/src_param/calc_prmwat.F90`, the exact branch `(rivwth0 > 0 OR rivwth0 == -1)` exposed a semantics question: treating `-1` as missing would change selected pixels and output area. The question was raised before implementing a replacement and answered in the maintainer-approved task specification.

## Verified facts

- Legacy code selects `rivwth == -1` together with positive width pixels.
- The maintainer confirmed positive values represent river-centerline width and `-1` represents water-surface pixels outside the river centerline.

## How was the knowledge formalized?

The v5 source comments and [`map/tools/script_params/README.md`](../../../map/tools/script_params/README.md#permanent-water-area) explain the class distinction. The `prmwat` row in `map/map_variables.csv` and the decision ADR-0004 retain the selection rule.

## Resolution trace

- Resolution method: mixed (source analysis and maintainer knowledge)
- Evidence or maintainer explanation: DR-0032 and HI-0004; legacy source branch in `map/src/src_param/calc_prmwat.F90`
- Final interpretation and rationale: `-1` is a water-surface class outside centerlines, not a missing sentinel for this calculation; include it to preserve the confirmed product definition.
- Formalization locations: `map/tools/code/param_water_calc_prmwat.F90`; `map/tools/script_params/README.md`; `map/map_metadata_spec.md`; `map/map_variables.csv`
- Human review: pending

## Verification and limits

The Mekong sample output matched legacy output byte-for-byte. This verifies migration behavior for the inspected sample and does not independently validate the class against remote sensing or establish all historical v4 documentation.

## Why the gap matters

Misclassifying `-1` as missing would omit non-centerline water surfaces from permanent-water area estimates.
