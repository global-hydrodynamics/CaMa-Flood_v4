# KG-0015: Intended MLIT level-gauge input table

- Gap ID: KG-0015
- Linked event IDs: EV-0179
- Category: input schema / provenance
- Evidence basis: wrapper and package inspection; intended substitution not confirmed
- Status: open

## What remains unknown?

Was MLIT_LevelGauge_allocated.csv intended to replace the missing MLIT_allocated.csv path in t03-alloc_level_gauge.sh, and what exact source/provenance and attribution should be retained with it?

## How was it discovered?

t03-alloc_level_gauge.sh names ../../data/MLIT_allocated.csv, but that file is absent from both the inspected repository data directory and the v4.30 package. The package contains MLIT_LevelGauge_allocated.csv, whose first four column names and record layout appear compatible with the reader's positional first-four-field contract. The filename and omitted processing history prevent treating the substitution as confirmed.

## Verified facts

- The level-gauge program skips one header row, then reads ID, latitude, longitude, and upstream area.
- The package's MLIT_LevelGauge_allocated.csv begins with ID,lat_alloc,lon_alloc,area_alloc and has 7,539 data rows.
- map/data/MLIT_allocated.csv is not present; the shell wrapper's reference is therefore not runnable with the inspected package contents.
- The package also has MLIT_FlowGauge_alloc_final.csv, but no corresponding workflow among the three inspected scripts consumes it.

## How was the knowledge formalized?

The mismatch and candidate replacement are explicitly marked in docs/map_allocation_migration_plan.md; the v5 level-gauge wrapper should not silently change to the candidate until this is confirmed.

## Resolution trace

- Resolution method: unresolved; maintainer confirmation/source manifest needed
- Evidence or maintainer explanation: map/src/src_param/t03-alloc_level_gauge.sh; map/src/src_param/allocate_level_gauge.F90; local package file inventory and CSV header inspection.
- Final interpretation and rationale: first-four-column compatibility is evidence of schema shape only, not proof of intended dataset identity or scientific equivalence.
- Formalization location(s): docs/map_allocation_migration_plan.md.
- Human review: pending

## Verification and limits

The observed file path, header, and row count are reproducible. The original authoring history and use intent of the two filenames were not available.

## Why the gap matters

Using the wrong station list could change the study population even when the executable can parse the file. It also affects reproducibility, provenance, and future documentation.
