# Knowledge gap template

- Gap ID: `KG-####`
- Linked event ID(s): `EV-####`
- Category: format / scientific assumption / workflow / dependency / architecture / interface / other
- Evidence basis: source-code evidence / maintainer-confirmed / AI inference / package observation / unresolved
- Status: open / formalized / verified / partially verified / closed

## What was unknown or assumed?

State the specific question without embedding an unverified answer. Identify whether it concerns v4 knowledge, a new v5 decision, or both.

## How was it discovered?

Record the discovery trigger and when it was recorded (contemporaneous or retrospective). Link the source file/lines, test, discussion, diff, or other artifact that exposed the question. Explain why the answer matters and what work depends on it.

## Verified facts

Separate source-backed facts from human explanation, inference, and remaining uncertainty.

## How was the knowledge formalized?

Link the specification, docs, tests, or code.
