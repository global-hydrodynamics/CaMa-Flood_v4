# Event-row checklist

Add one row to `research/events.csv` for each significant observed event, not each routine action. Assign the next unused `EV-####`. Required columns are timestamp, precision, type, actor, actor type, concise summary, outcome status, evidence class, and privacy status. Link related task and record IDs; use public evidence references where possible.

Record the status that actually occurred: a proposal is not approval; approval is not an implementation instruction; instruction is not implementation; execution is not validation; a passing check is not proof of scientific correctness. For unknown or restricted evidence, record that condition rather than guessing.
