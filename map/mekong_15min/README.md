# Mekong regional map example

This map directory is the development example for a regional map on a 15-minute (0.25°) grid, covering 90–110°E and 5–35°N. Its selected parent map for the current workstation verification is the linked `glb_15min` v400 dataset.

The reusable, general instructions for creating a regional map are in [`map/src/src_region/README.md`](../src/src_region/README.md). This page is limited to the Mekong example and does not claim that map generation or validation has completed. The development working copy and its current verification state are documented in [`src_region/README.md`](src_region/README.md).

The parent-map link is a development aid and is not suitable for distribution. A distributable package should contain the intended regional outputs and must not depend on a workstation-specific link to `glb_15min`.
