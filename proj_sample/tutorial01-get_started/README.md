# Tutorial01 — Get started

[`tutorial01-get_started.md`](tutorial01-get_started.md) is the tested first-run guide for the v5 Mekong sample. It builds the model and runs the maintained `gosh_sample/mek01-default_run.sh` with a tutorial-specific output directory.

The attached experiment design and manual-writing guide are retained here as the original comparison sources. [`manual_authoring_assessment.md`](manual_authoring_assessment.md) records lessons from the first AI-authored manual experiment. [`tutorial01-reset.sh`](tutorial01-reset.sh) is for developers preparing a clean documentation run; new users do not need it. The script prompts before cleaning and never changes `config/Mkinclude`.
